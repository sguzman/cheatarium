A repository-level license does not automatically settle every third-party contribution.

### Sharkive acquisition (2026-10-09)

The first pinned import contains **644 3DS text files** and **491 Switch text files** from upstream commit `aeab5fd3b001ed22c013efd1a02b092575d825ed`. The source manifest records original paths and exact Git blob hashes; original GPLv3 LICENSE and credit-bearing README are archived alongside the native text files. Three Switch build-ID filenames are nonstandard lengths and are preserved unchanged rather than renamed or interpreted as verified builds. There are 18,417 original bracketed section headings; these are archival text markers, not unique or tested effects. The generated distribution now includes **38 platform search bundles**: 36 original Libretro bundles plus 3DS and Switch. Sharkive native cheat sections are searchable by original title/build-ID paths with untouched multiline payloads, source ordinals and checksum-checked provenance. The file paths do not supply independently verified game names or ROM/build compatibility. Source-level reuse claims remain bounded by actual upstream licensing and contributions.

### Acquisitions through 2026-10-10

**33,110 actual original cheat files** are now preserved from fourteen separately pinned upstream repositories, with **33,076 indexed across 44 console bundles**. The remaining 34 are original Dolphin INIs with intentionally unassigned system identity. Recent acquisitions added **62 PS2 PNACH files from AeroWidescreen**, **278 Dolphin AR/Gecko code-bearing INIs**, **4 independent PS2 PNACH files** from SalustLab and PreachingPython, and **15 additional PS2 PNACH originals** from igorciz777 and Saupernova13. Non-cheat emulator settings and a binary ISO patch were excluded.

All sources retain unchanged byte-level originals and file-level Git blob SHA attribution. Licenses remain source-specific (Libretro CC BY-SA, various upstream MIT/GPL collections); upstream repository licensing is not a blanket clearance for every historical third-party author. Filename game IDs, serials, CRCs, builds and regions remain unverified source hints. No cheats are executed.

The GoldHEN archive also preserves its three original filename-to-game-title lists (`json.txt`, `shn.txt`, `mc4.txt`). The searchable source catalog now uses their **4,286 exact file-to-title associations** where applicable, while retaining each original source filename, title/build marker and Git provenance. Titles are upstream attribution labels, not independently established ROM/game-build identities. The opaque MC4 files without matching title-list records are not assigned guessed names.
