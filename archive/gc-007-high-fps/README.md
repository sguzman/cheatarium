## How to use
- click one of the games above and take the gecko code only, and add it as a new code to the game in dolphin.
- Go to dolphin settings/advanced then enable "VBI Frequency Override and match the vps to the fps the patch will be doing.
>So for example if its 120fps you would put it to "200%" or "119.88 VPS".
- Also in settings/general make sure cheats are enabled
